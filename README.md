# Non-frameable abort attribution

Artifact for *Non-Frameable Abort Attribution for Exponent-VRF Ceremonies: Delivery Boundaries and a Tag-Bound Schnorr Bridge*. It supplies deterministic finite models for the delivery boundary, generic attribution compiler, toy Schnorr-response bridge, encoding/setup boundaries, and restricted privacy interfaces.

## Environment and inputs

The supported reproduction path is **CPython 3.10+ on Linux**, including Linux under WSL2, with `sh` or `bash`. The artifact uses the Python standard library only; no package installation is needed. CI uses Python 3.12; the retained measured pilot used Linux x86_64 and Python 3.13.5.

The runner requires Linux `resource.setrlimit`, `resource.getrusage`, and `signal.SIGALRM`. Native Windows is unsupported and exits with a platform error before starting; macOS is outside the supported/measured path. Do not bypass the resource controls.

All cases are deterministic synthetic inputs generated by `src/`; no download, secret, private data, external model, GPU, live ceremony, or network service is required. Supply a **new or empty output directory**. Do not use `results/pilot/` as the output path: those retained results and measurements are the comparison baseline.

## Run and reproduce

From this directory, or the root of either flat public repository, on Linux/WSL2:

```sh
python3 -B -m unittest discover -s tests -v
python3 -B tests/regression_extraction_preparation.py -v
out=$(mktemp -d)
python3 -B reproduce.py --out "$out"
python3 -B compare_results.py results/pilot "$out"
python3 -B audit_references.py --inventory reference_audit.csv
```

Expected results:

- 107 main unit tests pass; the separate extraction regression has two methods covering 24 named fixtures.
- The runner exits 0 with `status = finite_checks_passed` and no unexpected failures.
- All **25** deterministic scientific output files match the retained pilot byte-for-byte.
- `measurements.json` contains process metadata and is deliberately excluded from byte comparison.

The runner refuses nonempty output directories and enforces one worker, 180 seconds wall/CPU, 3 GiB address space, and a 300,000-obligation cap. The retained run has 214,915 obligations plus separately recorded length/composition assertions. New host timings do not replace the retained measurements.

The extraction regression checks literal certificates and independent replay, canonical reference choice, exact closures, and content versus `D`/`D+1` timing. Extraction prepares record references and complaint candidates once per validated call; selected certificates still pass the standalone judge. No measured cryptographic or protocol speedup is claimed.

CI in `.github/workflows/scientific-checks.yml` runs the bounded checks on Ubuntu 24.04 and uploads raw output on success or failure. `.github/scripts/check_repository.py` is a separate source/configuration integrity check, not an experiment.

## Interpretation and conditions

The models are not production eVRF, NIZK, signature, consensus, or network implementations. eVRF verification is an imported ideal bit. The small group, Paillier modulus, and 251-value challenge space support finite conformance checks, not cryptographic security. The retained false-statement negative control is expected to be accepted by the toy proof verifiers; it demonstrates why this toy proof system must not be deployed.

The ideal/generic finite APIs require prime modulus and prime subgroup order within 16-bit trial-division bounds. Receipt authors use exact integers, not Boolean/float aliases. The Schnorr authentication registry rejects the identity key; zero-valued share/nonce tags remain legal. Public-history-only adaptive-policy regressions are separate from the retained pilot totals.

The paper theorem imports complete and sound real-setup verification for the exact bounded plaintext/tag relation. Compiled-view privacy is restricted to generated setup with matching retained signing state and a non-feedback semantic trace. It requires lawful same-length dummies, causal regeneration of public responses, a joint base simulator with retained auxiliary state, and a joint simulated-CRS/proof interface. Static corruption or simulation soundness alone does not supply these conditions; arbitrary ciphertext-driven private continuation is excluded. See the proof maps for the full conditions.

Passing these checks establishes finite encoding/specification consistency, not theorem correctness by enumeration, imported eVRF security, production NIZK security, complete board closures, deployment performance, independent human review, or mechanized verification.
